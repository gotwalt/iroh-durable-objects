# Documentation

- [`design.md`](design.md): the design as built. Start here.
- [`spec.md`](spec.md): the original plan, written before implementation.
  Where it disagrees with `design.md`, a design note explains why.
- [`design-notes/`](design-notes/): the decision log, numbered in order. Each
  note records a change to the plan and the evidence for it.
- [`verification.md`](verification.md) and [`verification/`](verification/):
  answers to the plan's open questions about iroh 1.4.0, workers-rs and
  Cloudflare, each citing the pinned source by file and line, or a
  reproduction.
- [`measurements/`](measurements/): cost and performance measurements, with
  the raw data and the scripts that produced them.
